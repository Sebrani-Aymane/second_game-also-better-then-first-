🎮 HOW TO PLAY
═══════════════════════════════════════════════════════════════════════

1. Enter a username and login

   - Minimum 3 characters

   - Squares light up in sequence
   - Each square has a unique tone

   - Click the squares in the same order
   - Pattern gets longer each round

   - 5 coins per round completed
   - High score is your personal best

6. Use the shop
   - Spend coins on avatars and items
   - View your progress

❓ FAQ
═══════════════════════════════════════════════════════════════════════

Q: Server won't start?
A: Make sure Node.js is installed. Try "npm install" in backend folder.

Q: "Cannot GET /" error?
A: Backend needs to be running. Make sure you're at localhost:3000

Q: Connection refused?
A: Port 3000 might be in use. Check with "lsof -i :3000" or use
   different port: PORT=5000 npm start

Q: Data disappears when I restart?
A: Currently using in-memory storage. Data resets on restart.
   Next step: Add MongoDB or PostgreSQL for persistence.

Q: Can I change the port?
A: Yes! Use: PORT=5000 npm start

Q: How do I stop the server?
A: Press Ctrl+C in the terminal
