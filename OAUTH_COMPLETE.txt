For Production Deployment:

1. Create Production Google OAuth App
   → New project in Google Console
   → New OAuth credentials for production
   → Use production domain (not localhost)

2. Set Environment Variables on Server
   Don't use .env file in production!
   Instead, set environment variables:
   $ export GOOGLE_CLIENT_ID=your_production_id
   $ export GOOGLE_CLIENT_SECRET=your_production_secret

3. Update Redirect URI
   Change from: http://localhost:3000/oauth/google/callback
   To: https://yourdomain.com/oauth/google/callback

4. Use HTTPS
   Google requires HTTPS for production OAuth
   Get SSL certificate (Let's Encrypt is free)

5. Database Integration
   Current setup uses in-memory storage
   For production, add MongoDB or PostgreSQL
   Data won't be lost on server restart
