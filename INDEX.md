## 🆘 Help

**If you get stuck:**
1. Check `GETTING_STARTED.txt` → FAQ section
2. Check `README.md` → Troubleshooting section
3. Check browser console (F12)
4. Check terminal output for error messages

**Common issues:**
- Port 3000 in use? → Use: `PORT=5000 npm start`
- Module not found? → Run: `cd backend && npm install`
- Page won't load? → Check if server is running
- API calls failing? → Check Network tab in DevTools
