GET /oauth/google/callback
  - Receives authorization code from Google
  - Exchanges code for access token
  - Verifies ID token with Google
  - Creates/updates user account
  - Redirects back to game with user data

How it works:
  1. User clicks "Continue with Google"
  2. Redirected to Google login page
  3. User logs in with Google account
  4. Google redirects back to endpoint above
  5. Backend verifies credentials
  6. Backend creates user if needed
  7. Frontend detects user and loads game
  8. You're logged in! ✅
